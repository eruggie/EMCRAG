## Use in the experiments

M1 uses the adapter in standalone generation. R1 enables it only in final EMCRAG generation; upstream visual expansion uses base MedGemma. The processor is loaded from the base repository by the historical inference code.

Prompt templates and decoding are unchanged in the release. Standalone inference uses a 2048-token configured budget, up to 512 new tokens, greedy decoding and repetition penalty 1.1.

## Evaluation

Standalone Response Relevancy declined from approximately 0.441 to 0.230 on 193 complete pairs. Pipeline Faithfulness increased from approximately 0.390 to 0.465 on 191 complete pairs. Changed contexts and cloud judging prevent attributing pipeline improvement to the adapter alone. These are textual evaluation results, not evidence of clinical correctness.

## Distribution conditions and proposed hosting

A future Hugging Face repository is preferable to storing this 119 MB weight file in normal GitHub Git history. Publish only the definitive final adapter, necessary small configs, exact hashes, a reviewed model card, required HAI-DEF terms/notice and justified data-use conditions; omit base weights, intermediate checkpoints, optimiser/RNG states and private records.

The code's Apache-2.0 licence does not apply to the adapter weights. MedGemma derivatives remain subject to [HAI-DEF terms](https://developers.google.com/health-ai-developer-foundations/terms). IMB is [CC BY-NC-ND 4.0](https://huggingface.co/datasets/praiselab-picuslab/IMB); that fact alone does not settle whether this trained adapter is adapted material or what redistribution rights apply. Obtain clarification or an appropriate permission before distributing weights or transformed records. This release deliberately makes no assertion that the weights are unrestricted open-source artefacts.
