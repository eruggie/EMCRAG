# Publication and version identifiers

Repository: https://github.com/eruggie/EMCRAG.
Scientific source tag: v1.0.0.

The neutral release identifiers refer to a frozen software snapshot. The exact commit is resolved by the annotated tag and the GitHub Release record. Source and copy checksums are listed in RELEASE_MANIFEST.csv and SHA256SUMS.

For a fresh local checkout:

```bash
git clone https://github.com/eruggie/EMCRAG.git
cd EMCRAG
git checkout v1.0.0
sha256sum --check SHA256SUMS
```

Future changes require a new reviewed commit and a distinct release tag. Do not overwrite a published scientific tag. Full preparation history and recovery records are kept privately in the author's local audit directory; they are not part of the public source release.

Cite https://github.com/eruggie/EMCRAG/tree/v1.0.0 together with the resolved commit identifier. No archival DOI is claimed.
