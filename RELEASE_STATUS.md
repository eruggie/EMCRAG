# Scientific source release

Version: v1.0.0.
Repository: https://github.com/eruggie/EMCRAG.
Release record: https://github.com/eruggie/EMCRAG/releases/tag/v1.0.0.

The release preserves nine historical system/preparation/benchmark notebooks, with two credential-environment substitutions, targeted output removals and a documented non-executable cell-id repair. Source code, parameters, prompts, paths and execution settings are unchanged from the reviewed implementation snapshot.

All nine notebooks pass the official format schema. Eighteen archived paired statistical groups were reproduced with the original pure numerical functions; the recovered manuscript-stage baseline rank-test/effect-size section was also checked on CPU.

Dataset records, raw clinical outputs, images and weights are excluded. The definitive adapter is identified but not distributed. The original baseline bootstrap workflow remains unavailable. See EXPERIMENT_AUDIT.md and MODEL_CARD.md.

No complete notebook, paid API evaluation, training or GPU benchmark was run during release preparation. The public release uses neutral software version identifiers; manuscript management is separate.
